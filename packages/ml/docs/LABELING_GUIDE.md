# 손톱 데이터 라벨링 가이드라인

## 개요

네일팁 사이즈 측정을 위한 손톱 감지 모델 학습용 데이터 라벨링 가이드입니다.

## 촬영 시나리오

### 시나리오 1: 엄지 촬영

```
┌─────────────────────────────────┐
│                                 │
│    ┌───────────────────────┐    │
│    │      신용카드          │    │
│    │                       │    │
│    │    ┌─────┐            │    │
│    │    │ 엄지 │            │    │
│    │    │ 손톱 │            │    │
│    │    └─────┘            │    │
│    │                       │    │
│    └───────────────────────┘    │
│                                 │
└─────────────────────────────────┘
```

- 엄지손톱을 정면에서 촬영
- 신용카드 위에 엄지를 올림
- 손톱이 카메라를 향하도록 각도 조절

### 시나리오 2: 네 손가락 촬영

```
┌─────────────────────────────────┐
│                                 │
│    ┌───────────────────────┐    │
│    │      신용카드          │    │
│    │                       │    │
│    │  ┌─┐ ┌─┐ ┌─┐ ┌─┐      │    │
│    │  │검│ │중│ │약│ │새│   │    │
│    │  │지│ │지│ │지│ │끼│   │    │
│    │  └─┘ └─┘ └─┘ └─┘      │    │
│    │                       │    │
│    └───────────────────────┘    │
│                                 │
└─────────────────────────────────┘
```

- 검지, 중지, 약지, 새끼손가락을 가지런히 배치
- 신용카드 위에 네 손가락을 올림
- 손톱이 위를 향하도록 평평하게

## 라벨링 규칙

### 1. 신용카드 (credit_card)

```
올바른 예:
┌─────────────────────────────┐
│  ┌───────────────────────┐  │
│  │ ┌─────────────────┐   │  │  ← 카드 전체를 감싸는 박스
│  │ │    VISA         │   │  │
│  │ │                 │   │  │
│  │ └─────────────────┘   │  │
│  └───────────────────────┘  │
└─────────────────────────────┘

잘못된 예:
┌─────────────────────────────┐
│    ┌─────────────────┐      │
│    │    VISA         │      │  ← 카드 일부만 포함 ❌
│    └─────────────────┘      │
└─────────────────────────────┘
```

**규칙:**
- 카드 전체 윤곽을 빈틈없이 감싸는 박스
- 카드 모서리가 박스 경계에 닿도록
- 그림자는 포함하지 않음

### 2. 손톱 (nail_*)

```
올바른 예:
        ┌───────────┐
        │ ┌───────┐ │
        │ │ 손톱  │ │  ← 손톱 영역만 타이트하게
        │ └───────┘ │
        └───────────┘

잘못된 예 1:
        ┌───────────┐
        │           │
        │   손톱    │  ← 손가락 피부까지 포함 ❌
        │           │
        └───────────┘

잘못된 예 2:
          ┌─────┐
          │손톱 │  ← 손톱 좌우 끝이 잘림 ❌
          └─────┘
```

**규칙:**
- 손톱 영역만 포함 (큐티클, 피부 제외)
- **좌우 경계가 정확해야 함** (가로폭 측정 목적)
- 상하 경계는 손톱 끝과 큐티클 라인
- 손톱 전체가 보이지 않으면 라벨링하지 않음

### 3. 손가락 구분 (4손가락 촬영 시)

```
왼손 촬영 시 (화면 기준):
 좌 ←――――――――――――――→ 우
┌─┐   ┌─┐   ┌─┐   ┌─┐
│검│   │중│   │약│   │새│
│지│   │지│   │지│   │끼│
└─┘   └─┘   └─┘   └─┘

오른손 촬영 시 (화면 기준):
 좌 ←――――――――――――――→ 우
┌─┐   ┌─┐   ┌─┐   ┌─┐
│새│   │약│   │중│   │검│
│끼│   │지│   │지│   │지│
└─┘   └─┘   └─┘   └─┘
```

**파일명 규칙으로 손 구분:**
- `left_four_001.jpg` → 왼손
- `right_four_001.jpg` → 오른손
- 메타데이터에 손 정보 포함

## 이미지 품질 기준

### 허용 ✅

| 조건 | 설명 |
|------|------|
| 자연광 | 창가, 야외 등 |
| 실내 조명 | 형광등, LED 조명 |
| 다양한 피부톤 | 밝은/중간/어두운 톤 |
| 자연 손톱 | 매니큐어 없는 상태 |
| 투명/누드 매니큐어 | 손톱 윤곽이 보이는 경우 |

### 제외 ❌

| 조건 | 이유 |
|------|------|
| 손톱이 가려짐 | 경계 측정 불가 |
| 심한 흔들림 | 경계 부정확 |
| 너무 어두움 | 손톱 구분 불가 |
| 카드가 잘림 | 스케일 기준 없음 |
| 손톱 일부만 보임 | 가로폭 측정 불가 |
| 화려한 네일아트 | v1에서 제외 (추후 지원) |

## 라벨링 워크플로우

### Step 1: 이미지 분류

```
raw_images/
├── good/           # 품질 OK → 라벨링 대상
├── bad/            # 품질 불량 → 제외
└── review/         # 판단 필요 → 리뷰
```

### Step 2: 라벨링

1. **신용카드 먼저** - 모든 이미지에서 카드 라벨링
2. **손톱 라벨링** - 보이는 모든 손톱 라벨링
3. **클래스 확인** - 올바른 손가락 클래스인지 확인

### Step 3: 검수

- 랜덤 샘플 10% 교차 검수
- 손톱 좌우 경계 정확도 집중 확인
- 오류율 5% 초과 시 재라벨링

## YOLO 형식 출력

```
# annotations/train/image001.txt

# class_id  x_center  y_center  width  height (모두 0~1 정규화)
0 0.5000 0.4000 0.6000 0.3500    # credit_card
1 0.3500 0.5500 0.0800 0.1200    # nail_thumb
```

### 좌표 계산

```
x_center = (bbox_left + bbox_width/2) / image_width
y_center = (bbox_top + bbox_height/2) / image_height
width = bbox_width / image_width
height = bbox_height / image_height
```
